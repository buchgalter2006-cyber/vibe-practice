# vibe-practice — учебный сервис отчётности

Рабочая папка практического трека «Вайбкодинг» (фазы 2–6). Трек и правила — в Obsidian: `Projects/Дмитрий — Практика вайбкодинг`. Все данные — **синтетика** (тестовый датасет), данные клиентов сюда не попадают.

## Структура

| Папка | Что внутри |
|---|---|
| `mockup/` | Ф2: макет дашборда — `index.html` (+`data.js`), открывается двойным кликом, без сборки |
| `data/` | тестовый датасет: `mock_data.json` + CSV (`plan_marketing`, `fact_marketing`, `dds_operations`) — сырьё для будущих источников |
| `scripts/` | `gen_test_data.py` — генератор датасета (детерминированный, seed=42; перегенерация меняет и CSV, и данные макета) |

## Как запустить

```bash
open mockup/index.html          # макет (Ф2)
python3 scripts/gen_test_data.py  # перегенерировать датасет + обновить mockup/data.js
```

## Дорожная карта

- ✅ **Ф2** — макет: 4 вкладки (Обзор, Маркетинг, Продажи, Метрики), переключатель периода, тестовые данные
- ⏭ **Ф3** — каркас приложения по промпту из макета; план → файл → новая сессия; git/GitHub
- ⏭ **Ф4** — данные: Google-таблица (план маркетинга), Excel (факт), FinTablo API, Битрикс24 вебхук — с проверкой цифр
- ⏭ **Ф5** — сервис: метрики с нормативами (НДС!), авторизация, загрузка Excel
- ⏭ **Ф6** — деплой на Amvera

## Конвенции

- Метрики считаются **без НДС** (ставка 22%), поступления из сервиса учёта — с НДС
- Сентябрь в датасете неполный (23 из 30 дней) — для Run Rate
- Макет — «одна страница — одна мысль», data-ink минимум (методология модуля 5 курса)
